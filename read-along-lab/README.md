# Article Read-Along Lab

영어 기사 PDF를 올리면 고른 수준(초등 5학년 · 중학교 1학년 · 원문 수준)에 맞춰 본문을 구성하고, 미국·영국 발음으로 듣고, 단어·이해 퀴즈·쓰기로 복습하는 학습실입니다.

- 주소: https://lijong454.github.io/read-along-lab/
- 수준별 본문과 문제 만들기에는 본인의 Anthropic API 키가 필요합니다. 키는 각자 브라우저에만 저장됩니다.
- 올린 PDF와 원문은 각자 브라우저에만 저장되며 이 저장소에는 올라가지 않습니다.
- 구글 드라이브 PDF는 기기의 파일 선택 창에서 Drive를 골라 가져옵니다.
