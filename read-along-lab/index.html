영어 기사 PDF를 올리면 원문 그대로 펼쳐 주고, 미국·영국 발음으로 들려줘요. 고른 난이도에 맞춰 Claude가 단어 15개, 이해 퀴즈, 쓰기 문제를 만들어요. 올린 기사는 이 기기에만 저장돼요.

아이폰 홈 화면에 앱처럼 추가하기

    기사와 진행 기록은 이 아이폰의 브라우저에만 저장돼요. 사파리와 Claude 앱은 저장 공간이 서로 달라서, 한쪽에서 올린 기사는 다른 쪽에 보이지 않아요. 한 곳을 정해서 쓰는 게 좋아요.

    Claude API 키입력 필요

    claude.ai 밖에서 수준별 본문과 단어·퀴즈·쓰기를 만들려면 내 Anthropic API 키가 필요해요. 키는 이 브라우저에만 저장되고 Claude API로만 보내요. 사용한 만큼 API 요금이 나가요(기사 한 편에 보통 수십~수백 원).

    키 만들기: console.anthropic.com › API Keys. 공용 컴퓨터에서는 쓰고 나서 ‘키 지우기’를 눌러 주세요. 같은 주소(lijong454.github.io)의 다른 페이지도 이 브라우저 저장소를 읽을 수 있으니 믿을 수 있는 페이지만 두세요.

    새 기사 올리기

      처음 쓸 때 Google Drive 사용 허락을 묻는 창이 떠요. 내 드라이브의 PDF만 보여요.

      단어·퀴즈·쓰기 문제의 난이도

      선택한 파일 없음
      1. PDF에서 글자 읽기
      2. Claude가 본문 문단 정리하기
      3. Claude가 고른 수준으로 본문과 문제 만들기

      1. PDF 올리기원문은 바뀌지 않고 그대로 보여요.
      2. 문장 누르기US / UK 발음을 골라 문장·문단을 들어요.
      3. 문제 풀기밑줄 단어, 퀴즈, 쓰기로 복습해요.

      처음 만들 때 Claude 사용 허락을 묻는 창이 떠요. 문제를 만드는 데 내 Claude 사용량이 조금 쓰여요.

      올린 PDF와 원문은 이 브라우저에만 저장되고 다른 사람에게 공유되지 않아요. 음성은 기기에 설치된 영어 음성을 써요. 크롬이나 엣지에서는 ‘Natural’, ‘Google’ 음성이, 아이폰·맥에서는 설정에서 내려받은 ‘향상된/고품질’ 음성이 가장 자연스러워요.
