# Golden Bell Daily 30

초등 6학년·중학교 1학년 영어 골든벨 상식 퀴즈 대회를 준비하는 학습 앱입니다. 매일 30문제(사지선다 9·단답형 21)를 시사 상식, 문학, 역사, 과학, 수학, 예술, 스포츠, 지리, 인물 9개 분야에서 냅니다.

- 주소: https://lijong454.github.io/golden-bell/
- 난이도는 4단계(기초 · 실력 · 심화 · 결승)이고, 한 세트를 80% 이상 맞히면 다음 단계로 올라갑니다.
- 단답형은 철자와 대문자·소문자까지 정답과 똑같아야 정답입니다.
- 학생별 기록(점수, 배지, 오답 노트)은 각자 브라우저에만 저장됩니다.
- 기본 문제 은행 360문제가 들어 있습니다. Claude로 새 문제를 더 만들려면 본인의 Anthropic API 키가 필요합니다. 키는 각자 브라우저에만 저장됩니다.
